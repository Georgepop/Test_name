# 🚚 Маршрутизация карьерных самосвалов

Проект предназначен для моделирования дорожной сети карьера и подготовки данных для оптимизации маршрутов самосвалов с помощью Python и Google OR-Tools CP-SAT.

Модель может учитывать структуру дорог, тип покрытия, характеристики машин, уклон участков и погодные условия.

## Возможности

- Представление дорожной сети в виде направленного графа.
- Хранение узлов и дорожных участков в CSV-файлах.
- Описание пунктов погрузки и разгрузки.
- Хранение характеристик самосвалов.
- Хранение почасовых погодных наблюдений.
- Расчёт уклона дороги по координатам и высотам узлов.
- Подготовка данных для оптимизации маршрутов с помощью OR-Tools CP-SAT.

## Формат входных данных

### `nodes.csv` — узлы дорожной сети

| Поле | Тип | Описание |
|---|---|---|
| `node_id` | string | Уникальный идентификатор узла |
| `kind` | string | Тип узла: `junction`, `load` или `dump` |
| `x_m` | float | Координата X в метрах |
| `y_m` | float | Координата Y в метрах |
| `z_m` | float | Высота узла в метрах |

Типы узлов:
- `junction` — перекрёсток или промежуточный узел.
- `load` — пункт погрузки.
- `dump` — пункт разгрузки.

Пример:

```csv
node_id,kind,x_m,y_m,z_m
S1,junction,0,0,100
A,junction,100,100,105
L,load,200,100,108
D,dump,500,300,90
```

### `edges.csv` — направленные дорожные участки

| Поле | Тип | Описание |
|---|---|---|
| `edge_id` | string | Уникальный идентификатор участка |
| `from_node` | string | Начальный узел |
| `to_node` | string | Конечный узел |
| `length_m` | float | Длина участка в метрах |
| `surface` | string | Тип дорожного покрытия |

Поддерживаемые типы покрытия:
- `paved` — твёрдое покрытие.
- `gravel` — гравийная дорога.
- `dirt` — грунтовая дорога.

Пример:

```csv
edge_id,from_node,to_node,length_m,surface
E1,S1,A,100,paved
E2,A,S1,100,paved
E3,A,L,150,gravel
E4,L,A,150,gravel
E5,E,D,250,gravel
```

**Важно:** граф направленный. Если движение разрешено в обе стороны, нужно создать отдельные записи для `A → B` и `B → A`. Для односторонней дороги достаточно одной записи.

### `vehicles.csv` — самосвалы

| Поле | Тип | Описание |
|---|---|---|
| `vehicle_id` | string | Уникальный идентификатор машины |
| `model` | string | Модель самосвала |
| `capacity_t` | float | Грузоподъёмность в тоннах |

Пример:

```csv
vehicle_id,model,capacity_t
Truck_1,BelAZ_7513,45
Truck_2,BelAZ_7547,60
Truck_3,CAT_777,90
```

Грузоподъёмность хранится в исходных данных. Чтобы учитывать её при оптимизации, необходимо добавить соответствующие ограничения в модель.

### `weather.csv` — погодные условия

Погода задаётся с часовым интервалом.

| Поле | Тип | Описание |
|---|---|---|
| `ts` | datetime | Дата и время наблюдения |
| `precip_mm_h` | float | Интенсивность осадков в мм/ч |
| `visibility_m` | float | Видимость в метрах |

Пример:

```csv
ts,precip_mm_h,visibility_m
2026-10-26 08:00:00,0.0,10000
2026-10-26 09:00:00,0.5,8000
2026-10-26 10:00:00,1.5,5000
2026-10-26 11:00:00,3.0,2500
```

Чтобы учитывать погоду в расчётах, нужно определить, как осадки и видимость влияют на скорость движения.

## Расчёт уклона дороги

Уклон участка рассчитывается по высотам начального и конечного узлов.

Горизонтальное расстояние:

```text
d = sqrt((x2 - x1)^2 + (y2 - y1)^2)
```

Уклон:

```text
slope = (z2 - z1) / d
```

Уклон в процентах:

```text
slope_percent = slope * 100
```

- Положительный уклон — движение вверх.
- Отрицательный уклон — движение вниз.
- Нулевой уклон — узлы находятся на одинаковой высоте.

## Параметры модели

Пример настроек в `graph_data.py`:

| Параметр | Значение | Описание |
|---|---:|---|
| `NUM_VEHICLES` | 20 | Количество машин |
| `TIME_STEP` | 10 секунд | Шаг времени |
| `HORIZON` | 3600 шагов | Горизонт планирования |
| `LOAD_TIME` | 20 секунд | Время погрузки |
| `DUMP_TIME` | 15 секунд | Время разгрузки |

Горизонт планирования:

```text
MAX_TIME = TIME_STEP × HORIZON
```

При указанных настройках он составляет 36 000 секунд, или 10 часов.

Время погрузки и разгрузки — демонстрационные параметры.

## Пропускная способность дорог

Пример параметров покрытия:

| Покрытие | Коэффициент скорости | Пропускная способность |
|---|---:|---:|
| `paved` | 1.00 | 3 машины |
| `gravel` | 0.75 | 2 машины |
| `dirt` | 0.50 | 1 машина |

Эти значения условные. Чтобы ограничение пропускной способности влияло на маршрутизацию, его необходимо явно реализовать в оптимизационной модели.

## Пропускная способность узлов

Пример начальных параметров:

```python
NODE_CAPACITY = {
    node["node_id"]: 1
    for node in NODES
}
```

Здесь каждому узлу задана вместимость в одну машину. В модели важно различать:
- **Вместимость узла** — сколько машин может одновременно находиться в узле.
- **Пропускную способность дороги** — сколько машин может одновременно двигаться по участку.
- **Очередь** — порядок прибытия и обслуживания машин.
- **Время ожидания** — время ожидания освобождения узла, дороги или пункта обслуживания.

Само наличие параметров в данных не вводит ограничения в оптимизатор: их нужно включить в модель.

## Запуск

После создания `graph_data.py` с переменными и функцией `export_csv()` запустите:

```bash
python graph_data.py
```

CSV-файлы будут сохранены в текущую рабочую директорию. Чтобы сохранять их в папку `data`, вызовите:

```python
export_csv("data")
```
