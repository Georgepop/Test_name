# 🚚 Маршрутизация карьерных самосвалов

Проект предназначен для моделирования дорожной сети карьера и подготовки данных для оптимизации маршрутов самосвалов с помощью Python и Google OR-Tools CP-SAT.

Модель может учитывать структуру дорог, тип покрытия, характеристики машин, уклон участков и погодные условия.

## 🎯 Описание проекта

Проект решает задачу **маршрутизации парка карьерных самосвалов** в условиях:
- Разнородного дорожного покрытия (асфальт, гравий, грунт);
- Рельефа местности с подъёмами и спусками;
- Ограниченной пропускной способности дорог и пунктов погрузки/разгрузки.

**Входные данные:**
- Граф карьерной сети (14 вершин, 36 рёбер);
- Парк из 20 самосвалов трёх моделей;
- Физические параметры (координаты, длины, уклоны).

**Выходные данные:**
- Оптимальный маршрут для каждого самосвала;
- Расписание движения (время старта, проезда, обслуживания);
- Визуализация графа с маршрутами;
- JSON-отчёт `result.json`.
