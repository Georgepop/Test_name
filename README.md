Моими словами:
Шаг 1:

Мы ищем короткие маршруты для каждой машины.

Шаг 2:

Далее мы смотрим, какие из этих маршрутов нам подходят.

Машины все стартуют из своих текущих точек.

На каждой дороге есть очереди, то:

Машина подъезжает к дороге (дорога имеет пропускную способность), встает в очередь.

Машина из текущей точки либо должна доехать до D, либо до L, потом D.

Параметры ребра (дороги):

1. Вместимость
2. Скорость* тип  погоду загруженность
3. Расстояние

Минимизируем общее время машин.
